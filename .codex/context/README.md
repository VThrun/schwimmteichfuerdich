# Project context

Last verified: August 20, 2026

This directory is the canonical project context for Design Draft 1. The
repository contains the first static design draft for the German
“Schwimmteich für Dich” website. It demonstrates the information architecture
and visual direction for swimming ponds, natural pools, bathing ponds, and
custom water projects; it is not yet a publication-ready company website.

Read the file that matches the task:

- [decisions.md](decisions.md) for durable architecture, stack, tooling, and
  verification decisions
- [site-structure.md](site-structure.md) for routes, module ownership, and
  page structure
- [content-status.md](content-status.md) for placeholder, publication, and
  external-service limits
- [design.md](design.md) for the selected theme and visual boundaries
- [conventions.md](conventions.md) for implementation and content conventions
- [key-commands.md](key-commands.md) for setup, development, and validation
  commands

General working rules remain in [`AGENTS.md`](../../AGENTS.md). The historical
site analysis in [`OLD_SITE_ANALYSIS.md`](../../OLD_SITE_ANALYSIS.md) is research
material and is not approved publication content. This draft does not use
daisyUI Blueprint or Blueprint MCP.
